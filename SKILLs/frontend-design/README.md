# Frontend Design

创建具有高品质设计的独特、生产级前端界面。

## 功能描述

Frontend Design Skill 帮助用户构建具有独特视觉风格的 Web 组件、页面、应用程序或界面。生成具有卓越美学细节和创意选择的实用代码，避免通用的"AI 风格"。

## 使用方法

### 设计思考

在编码前，理解上下文并确定大胆的美学方向：

- **目的**：这个界面解决什么问题？谁使用它？
- **调性**：选择极端风格：极简主义、极繁主义、复古未来主义、有机/自然、奢华/精致、 playful/玩具风格、编辑/杂志风格、粗野主义/原始风格、装饰艺术/几何风格、柔和/粉彩风格、工业/实用主义风格等
- **约束**：技术要求（框架、性能、可访问性）
- **差异化**：什么让这令人难忘？有人会记住的一件事是什么？

### 前端美学指南

**排版**：
- 选择美观、独特、有趣的字体
- 避免通用字体如 Arial 和 Inter
- 选择能提升前端美学的独特字体
- 将独特的展示字体与精致的正文字体配对

**色彩与主题**：
- 坚持统一的美学
- 使用 CSS 变量保持一致性
- 主色调配锐利点缀色优于胆怯的均匀分布调色板

**动效**：
- 使用动画实现效果和微交互
- HTML 优先使用纯 CSS 解决方案
- 使用 Motion 库处理 React
- 专注于高影响力时刻

**空间构图**：
- 意想不到的布局
- 不对称
- 重叠
- 对角线流动
- 打破网格的元素
- 大量负空间或有控制的密度

**背景与视觉细节**：
- 创造氛围和深度
- 添加上下文效果和纹理
- 渐变网格、噪点纹理、几何图案、分层透明度、戏剧性阴影、装饰边框、自定义光标、颗粒叠加

### 避免通用 AI 美学

**绝不使用**：
- 过度使用的字体家族（Inter、Roboto、Arial、系统字体）
- 陈词滥调的色彩方案（特别是白色背景上的紫色渐变）
- 可预测的布局和组件模式
- 缺乏上下文特定特征的千篇一律设计

## 使用示例

**用户请求：** "帮我创建一个产品落地页"

**执行步骤：**
1. 分析产品类型和目标受众
2. 选择独特的设计方向（如：粗野主义、编辑风格、有机自然等）
3. 创建生产级、功能完整的代码
4. 确保视觉上引人注目且令人难忘

## 输出格式

- HTML/CSS/JS
- React 组件
- Vue 组件
- 其他前端框架

## 依赖要求

根据项目需求而定，可能包括：
- Node.js
- React/Vue 等框架
- CSS 动画库
- 图标库

## 注意事项

- 根据美学愿景匹配实现复杂度
- 极繁主义设计需要精心编排的动画和效果
- 极简主义设计需要克制、精确和对间距、排版、细节的细致关注
- 优雅来自于很好地执行愿景
- 每次设计都应该不同
- 在浅色和深色主题、不同字体、不同美学之间变化
