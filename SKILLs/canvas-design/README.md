# Canvas Design

使用设计哲学创建精美的视觉艺术作品（PNG/PDF）。

## 功能描述

Canvas Design Skill 帮助用户创建原创的视觉设计作品，包括海报、艺术品、设计图等静态视觉内容。通过"设计哲学"方法论，将创意概念转化为高质量的视觉表达。

## 使用方法

### 基本流程

1. **创建设计哲学**（.md 文件）
   - 定义视觉美学方向
   - 描述空间、色彩、构图原则
   - 强调工艺感和专业水准

2. **在画布上表达**（.pdf 或 .png 文件）
   - 将设计哲学转化为视觉作品
   - 90% 视觉设计 + 10% 必要文字
   - 输出高质量的艺术作品

### 使用示例

**用户请求：** "帮我设计一张关于'城市与自然'主题的海报"

**执行步骤：**
1. 首先创建设计哲学文档，定义视觉风格
2. 然后基于该哲学创作视觉作品
3. 输出为 PDF 或 PNG 格式

### 设计哲学示例

**"混凝土诗歌"**
- 通过大胆的几何形态进行视觉传达
- 巨大的色块、雕塑般的排版
- 波兰海报能量与柯布西耶风格的结合

**"色彩语言"**
- 色彩作为主要信息系统
- 几何精确度，色彩区域创造意义
- 受约瑟夫·阿尔伯斯色彩互动理论启发

## 核心原则

- **视觉优先**：信息通过设计传达，而非大段文字
- **极简文字**：文字作为视觉元素，而非说明
- **空间表达**：通过空间、形态、色彩、构图传达思想
- **专业工艺**：作品应体现大师级的工艺水准
- **原创设计**：避免抄袭现有艺术家作品

## 输出格式

- **PNG**：单页高质量图像
- **PDF**：单页或多页设计文档
- **MD**：设计哲学说明文档

## 依赖要求

- Node.js 运行时
- 字体文件（位于 `./canvas-fonts` 目录）

## 注意事项

- 所有视觉元素必须包含在画布边界内
- 文字不应重叠或超出页面
- 使用多种字体增强视觉效果
- 追求博物馆级别的作品质量
