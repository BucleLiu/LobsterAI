# Skill Creator

创建新技能、修改和改进现有技能，以及测量技能性能。

## 功能描述

Skill Creator Skill 提供了完整的技能开发和优化工作流，支持：
- 从头创建新技能
- 更新或优化现有技能
- 运行评估测试技能
- 使用方差分析基准测试技能性能
- 优化技能描述以提高触发准确性

## 使用方法

### 创建技能流程

1. **确定意图**
   - 这个技能应该让 Claude 能够做什么？
   - 什么时候应该触发这个技能？
   - 预期的输出格式是什么？
   - 是否需要设置测试用例？

2. **访谈和研究**
   - 主动询问边缘情况
   - 了解输入/输出格式
   - 确认成功标准
   - 检查依赖关系

3. **编写 SKILL.md**
   - **name**: 技能标识符
   - **description**: 何时触发，做什么
   - **compatibility**: 所需工具、依赖项
   - 其余技能内容

### 技能结构

```
skill-name/
├── SKILL.md (必需)
│   ├── YAML frontmatter (name, description 必需)
│   └── Markdown 说明
└── 捆绑资源 (可选)
    ├── scripts/    - 可执行代码
    ├── references/ - 按需加载的文档
    └── assets/     - 输出中使用的文件
```

### 渐进式披露

技能使用三级加载系统：
1. **元数据**（name + description）- 始终在上下文中
2. **SKILL.md 正文** - 技能触发时在上下文中
3. **捆绑资源** - 按需加载

### 运行和评估测试用例

1. **生成所有运行**（with-skill AND baseline）
2. **运行进行时起草断言**
3. **运行完成时捕获计时数据**
4. **评分、聚合并启动查看器**
5. **读取反馈**

### 改进技能

基于反馈改进技能：

1. **从反馈中泛化** - 创建适用于多种情况的技能
2. **保持提示精简** - 移除无效内容
3. **解释原因** - 解释为什么要求模型做某事
4. **寻找跨测试用例的重复工作** - 提取到 scripts/

### 描述优化

优化技能描述以提高触发准确性：

1. **生成触发评估查询** - 创建 20 个评估查询（混合应该触发和不应该触发）
2. **与用户审查** - 使用 HTML 模板展示评估集
3. **运行优化循环** - 在后台运行优化
4. **应用结果** - 使用最佳描述更新 SKILL.md

## 测试用例格式

保存到 `evals/evals.json`：

```json
{
  "skill_name": "example-skill",
  "evals": [
    {
      "id": 1,
      "prompt": "用户的任务提示",
      "expected_output": "预期结果的描述",
      "files": []
    }
  ]
}
```

## 依赖要求

- Python 3.8+
- Node.js（用于某些脚本）
- Claude CLI 工具（用于描述优化）

## 注意事项

- 技能必须不包含恶意软件、漏洞利用代码
- 技能内容不应让用户感到意外
- 保持 SKILL.md 在 500 行以内
- 大参考文件（>300 行）应包含目录
- 使用祈使形式编写说明
- 解释为什么事情重要，而不是大量 MUST
